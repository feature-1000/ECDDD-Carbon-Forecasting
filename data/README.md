# Data

This directory stores empirical and synthetic data used by the experiments.

## Carbon Monitor Data

`raw/CM_emission_kton.csv` is a Carbon Monitor daily carbon emission file.

- Source: https://carbonmonitor.org.cn/
- Format: long-table CSV
- Columns: `date`, `sector`, `country`, `co2`
- Default empirical subset in `config.yaml`: `country = China`, `sector = Power`

Please check the Carbon Monitor website for the most recent data terms and updates.

## Synthetic Data

The synthetic AR drift sequences used for drift detection experiments are generated by `synthetic_data.py`. They reproduce the three autoregressive benchmark groups described in the manuscript.
